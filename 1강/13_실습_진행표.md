# ChatGPT 웹 업무 비서 실습 진행표
총 69쪽 교안과 함께 사용합니다. 모든 사례는 가상입니다.

## 9쪽 · 첫 실행: 메모에서 할 일 한 개 찾기
새 대화에서 짧은 입력으로 응답을 받고, 이어서 한 번 수정합니다.

1. 새 대화: 왼쪽 새 채팅을 엽니다.
2. 메모 입력: “금요일까지 행사 안내문을 수정한다. 담당자는 아직 정하지 않았다.”
3. 요청 실행: 아래 요청문을 입력하고 전송합니다.
4. 확인·수정: 담당자가 미정인지 봅니다. 이어서 “한 문장으로 줄여주세요”를 입력합니다.

실행 요청:
이 메모에서 할 일·기한·담당자를 정리해 주세요. 메모에 없는 담당자는 미정으로 표시해 주세요.

완료 확인: 할 일과 기한이 맞고, 담당자는 미정으로 표시됩니다.

## 13쪽 · 회의 비서 실행 순서
파일 첨부부터 후속 업무표 확인까지 한 번에 진행합니다.

1. 새 대화: 새 채팅을 열고 + 메뉴를 선택합니다.
2. 자료 첨부: 02_회의메모.txt를 추가합니다. 파일명을 확인합니다.
3. 업무 요청: 아래 요청문을 전송하고 정리 결과를 기다립니다.
4. 원문 대조: 안내문 담당자, 장소 확인 기한, 명단 담당자를 원문과 비교합니다.

실행 요청:
회의 메모를 결정사항과 후속 업무로 정리해 주세요. 업무·담당자·기한·상태를 적고, 없는 내용은 미정으로 표시해 주세요.

완료 확인: 원문과 일치하는 업무표 1개

## 18쪽 · 일정 비서 실행과 변경
한 번 작성한 일정표에 변경 조건을 이어서 반영합니다.

1. 자료 추가: 01_하루업무.txt를 새 대화에 첨부합니다.
2. 일정 작성: 아래 요청문으로 시간표를 만듭니다.
3. 조건 변경: “회의를 13시 30분–14시로 바꿉니다”라고 입력합니다.
4. 마감 확인: 오후 3시 제출과 작성 90분을 모두 만족하는지 봅니다.

실행 요청:
고정 일정과 업무 소요 시간을 반영해 오늘 시간표를 작성해 주세요. 마감 전에 끝나는지 확인하고 불가능한 조건은 알려주세요.

완료 확인: 변경 전·후 일정표와 마감 확인

## 22쪽 · 메일 비서 실행과 결과 검토
원문과 답변 조건을 함께 넣고, 실제 회신 문구를 검토합니다.

1. 자료 첨부: 08_문의메일.txt를 추가합니다.
2. 초안 요청: 질문에 대한 답장을 제목과 본문으로 요청합니다.
3. 표현 확인: 일시·준비물·예약 확인 중의 세 내용을 봅니다.
4. 짧게 변경: 같은 답장을 휴대전화 안내 문자 3문장으로 줄입니다.

실행 요청:
첨부한 문의에 답하는 정중한 회신을 작성해 주세요. 14–16시, 개인 노트북, 장소 예약 확인 중을 포함해 주세요.

완료 확인: 메일 초안 1개와 안내 문자 1개

## 27쪽 · Work 보고 파일 작성
자료를 첨부하고 파일 생성까지 요청합니다.

1. 파일 추가: 09_주간업무.txt와 12_보고형식.txt를 첨부합니다.
2. 업무 시작: 아래 요청문을 입력하여 실행합니다.
3. 진행 확인: 추가 질문이 나오면 범위와 형식을 답합니다.
4. 파일 열기: 완료된 파일을 열고 제목·항목·숫자를 확인합니다.

실행 요청:
첨부 자료로 A4 1쪽 주간보고.docx를 만들어 주세요. 보고 형식의 항목과 순서를 유지하고, 미확정 내용은 확인 필요로 남겨주세요.

완료 확인: 다운로드 가능한 보고 파일 1개

## 29쪽 · 파일 수정과 재사용
완성된 파일을 다시 열어 필요한 부분을 구체적으로 수정합니다.

1. 수정 대상: 보고서에서 고칠 항목을 찾습니다.
2. 추가 사실: “신청 3건이 추가 접수되어 총 15건입니다”라고 알립니다.
3. 유지 조건: 제목·항목 순서·나머지 사실을 유지하도록 요청합니다.
4. 최종 확인: 수정 파일을 열고 총 15건으로 반영되었는지 봅니다.

실행 요청:
참석 신청을 총 15건으로 수정해 주세요. 제목과 항목 순서, 나머지 사실은 유지하고 수정된 전체 파일을 제공해 주세요.

완료 확인: 같은 형식을 유지한 수정 파일

## 35쪽 · 자료 세 개를 대화에 첨부
자료가 실제로 첨부되었는지 확인한 뒤 질문합니다.

1. 새 대화: 새 채팅을 열고 입력창의 +를 선택합니다.
2. 파일 선택: 03·04·05번 TXT 파일을 선택합니다.
3. 첨부 확인: 파일 세 개의 이름과 첨부 완료 상태를 확인합니다.
4. 읽기 확인: “첨부한 파일명과 각 문서 주제를 알려주세요”를 실행합니다.

실행 요청:
첨부한 파일명과 각 문서의 주제를 알려주세요. 읽지 못한 파일이 있으면 표시해 주세요.

완료 확인: 파일 3개의 구분과 읽기 상태 확인

## 36쪽 · 자료 비서에게 첫 질문
공간과 비용, 예약 상태를 함께 묻습니다.

1. 조건 확인: 9월 30일, 18명, 2시간을 질문에 적습니다.
2. 범위 지정: 첨부 자료를 기준으로 답하도록 요청합니다.
3. 근거 요청: 파일명·항목·근거 문장을 답변에 포함합니다.
4. 결과 검토: B실, 50,000원, 예약 미확정을 확인합니다.

실행 요청:
첨부 자료 기준으로 9월 30일 18명이 2시간 사용할 공간과 사용료를 알려주세요. 계산식·예약 상태·파일명과 근거 항목을 적어주세요.

완료 확인: 근거가 붙은 답변 1개

## 42쪽 · RAG 실습: 행사 준비표 완성
문서 세 개를 함께 사용하여 준비와 미확인 사항을 정리합니다.

1. 자료 확인: 03·04·05번 파일을 사용합니다.
2. 준비표 요청: 장소·요금·기한과 장비·공지·주차를 넣도록 요청합니다.
3. 근거 확인: 답변의 근거 두 곳을 파일에서 직접 찾습니다.
4. 누락 점검: 공지 담당자 미정과 주차 확인 필요가 있는지 확인합니다.

실행 요청:
세 문서로 행사 준비표를 작성해 주세요. 항목·준비 내용·근거·확인 상태를 적고 자료에 없는 정보는 확인 필요로 남겨주세요.

완료 확인: 준비표 1개와 원문 근거 2곳

## 47쪽 · 프로젝트에 실습 자료 추가
프로젝트 안에 참고자료가 보관되었는지 확인합니다.

1. 프로젝트 열기: 가온센터 행사 비서를 엽니다.
2. 자료 추가: 프로젝트의 파일·자료 추가 메뉴를 선택합니다.
3. 파일 등록: 03·04·05번 TXT 파일을 올립니다.
4. 목록 확인: 프로젝트 자료 목록에서 파일 3개를 확인합니다.

실행 요청:
이 프로젝트에 있는 자료의 파일명과 주제를 정리해 주세요.

완료 확인: 프로젝트 자료 3개와 읽기 확인

## 49쪽 · 새 대화에서 비서 재사용
프로젝트 밖으로 나가지 않고 새 질문을 시작합니다.

1. 새 대화: 프로젝트 안에서 새 채팅을 선택합니다.
2. 질문 실행: 아래 질문을 입력합니다.
3. 규칙 확인: 근거와 미확인 사항이 구분되어 있는지 봅니다.
4. 자료 확인: 답변이 사용한 파일이 프로젝트 자료와 같은지 확인합니다.

실행 요청:
9월 30일 행사 준비에서 아직 확인할 일을 정리해 주세요. 담당자와 기한, 근거를 적어주세요.

완료 확인: 예약·공지 담당자·주차의 미확인 상태 확인

## 54쪽 · 한 번 실행할 알림 등록
시간을 지정할 수 있는 계정은 짧은 알림으로 먼저 시험합니다.

1. 요청 입력: “5분 뒤 실습 자료 확인을 한 번 알려주세요”를 입력합니다.
2. 등록 확인: 작업 생성 확인과 예약 목록을 확인합니다.
3. 시간 확인: 날짜·시간·한국시간·한 번 실행을 확인합니다.
4. 결과 확인: 알림이 온 뒤 작업 결과를 엽니다.

실행 요청:
한국시간 기준으로 5분 뒤에 “실습 자료를 확인하세요”라고 한 번 알려주세요.

완료 확인: 예약 등록과 실제 실행 결과

## 58쪽 · 반복 실행: 매주 업무 정보 브리핑
일정에 맞춰 공개 정보를 조사하는 작업을 등록합니다.

1. 주제 선택: 예: 서울시 중장년 디지털 교육 공지
2. 시점 지정: 매주 월요일 오전 9시, 한국시간을 적습니다.
3. 내용 지정: 새 공지 3건의 제목·날짜·공식 링크를 요청합니다.
4. 결과 점검: 등록 일정과 첫 실행 결과의 출처를 확인합니다.

실행 요청:
매주 월요일 오전 9시 한국시간에 서울시 공식 사이트의 중장년 디지털 교육 새 공지를 찾아 제목·날짜·링크로 알려주세요. 새 공지가 없으면 없다고 알려주세요.

완료 확인: 정기 브리핑 작업 1개

## 62쪽 · 웹 조사 비서 실행
ChatGPT 웹 검색으로 조건에 맞는 공개 자료를 확인합니다.

1. 검색 요청: 새 대화에서 주제와 지역을 적고 웹 검색을 요청합니다.
2. 범위 설정: 공식 기관 자료를 우선하도록 요청합니다.
3. 출처 열기: 답변에 붙은 공식 링크를 열어봅니다.
4. 정보 확인: 게시일·신청 기간·대상을 원문과 비교합니다.

실행 요청:
서울시 중장년 대상 디지털 교육 모집 공지를 웹에서 찾아주세요. 공식 사이트를 우선하고 신청 기간·대상·원문 링크·확인 날짜를 적어주세요.

완료 확인: 공식 원문으로 확인한 공지 1건

## 65쪽 · 종합 실습: 나의 업무 비서 하나 완성
회의·보고·규정 확인·예약 중 자신의 업무 하나를 선택합니다.

1. 업무 선택: 반복하는 일과 완성할 결과를 한 문장으로 적습니다.
2. 기능 실행: Chat·Work·Projects와 Scheduled 중 사용할 기능을 엽니다.
3. 결과 검토: 사실 두 곳과 미확인 항목을 확인합니다.
4. 다시 사용: 자료 또는 조건 하나를 바꾸어 다시 실행합니다.

실행 요청:
제 업무는 [업무명]입니다. [자료]를 사용해 [결과]를 만들어 주세요. [조건]을 지키고 확인할 사항을 따로 남겨주세요.

완료 확인: 검토한 결과 1개와 재실행 결과
